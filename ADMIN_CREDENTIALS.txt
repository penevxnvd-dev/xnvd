📋 ИНСТРУКЦИИ ЗА СЪЗДАВАНЕ:

Вариант 1: Чрез Supabase Dashboard (най-лесно)
─────────────────────────────────────────────────────────────
1. Отидете в: https://supabase.com/dashboard
2. Изберете вашия проект
3. Отидете в: Authentication > Users
4. Кликнете "Add user" > "Create new user"
5. Въведете:
   - Email: admin@xnvd.com
   - Password: Admin123!
   - Auto Confirm User: ✅ (активирайте)
6. След създаване, отидете в SQL Editor
7. Изпълнете следния SQL:

   INSERT INTO public.user_roles (user_id, role)
   SELECT id, 'admin'::app_role
   FROM auth.users
   WHERE email = 'admin@xnvd.com'
   ON CONFLICT (user_id, role) DO NOTHING;

Вариант 2: Чрез скрипт (ако имате SERVICE_ROLE_KEY)
─────────────────────────────────────────────────────────────
1. Намерете SERVICE_ROLE_KEY в Supabase Dashboard:
   Settings > API > service_role key (секретен)

2. Задайте environment variable:
   export SUPABASE_SERVICE_ROLE_KEY="your-service-role-key"

3. Стартирайте:
   node create-admin.js
