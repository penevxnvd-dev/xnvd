## 🔧 Команди

### Стартиране
```bash
npm run dev
```

### Спиране
```bash
# Намерете процеса
ps aux | grep vite

# Или спрете на порта
lsof -ti:5173 | xargs kill -9
```

### Build за production
```bash
npm run build
```
