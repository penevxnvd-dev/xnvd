# Скриптове за управление на XNVD приложението

## 🚀 Рестарт на приложението

```bash
./restart-app.sh
```

Този скрипт:
- ✅ Спира всички процеси на портовете 3001 (Backend) и 8080 (Frontend)
- ✅ Убива всички свързани процеси (tsx, vite)
- ✅ Стартира Backend сървъра на порт 3001
- ✅ Стартира Frontend сървъра на порт 8080
- ✅ Проверява дали сървърите са стартирали успешно
- ✅ Показва статус и логове

## 🛑 Спиране на приложението

```bash
./stop-app.sh
```

Този скрипт:
- ✅ Спира всички процеси на портовете 3001 и 8080
- ✅ Убива всички свързани процеси (tsx, vite)

## 📊 Порти

- **Backend**: http://localhost:3001
- **Frontend**: http://localhost:8080

## 📝 Логове

- **Backend логове**: `/tmp/xnvd-backend.log`
- **Frontend логове**: `/tmp/xnvd-frontend.log`

## 🔍 Проверка на статуса

```bash
# Проверка на Backend
curl http://localhost:3001/api/health

# Проверка на Frontend
curl http://localhost:8080
```

## 💡 Употреба

1. За рестарт на приложението:
   ```bash
   ./restart-app.sh
   ```

2. За спиране на приложението:
   ```bash
   ./stop-app.sh
   ```

3. За проверка на логовете:
   ```bash
   tail -f /tmp/xnvd-backend.log
   tail -f /tmp/xnvd-frontend.log
   ```

## ⚠️ Забележки

- Скриптовете изискват `lsof` за проверка на портовете
- Ако порт 8080 е зает, Vite автоматично ще използва следващия свободен порт
- Всички процеси се убиват с `kill -9` за бързо спиране
